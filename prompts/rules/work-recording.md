# 작업 기록 규칙

**이 파일은 트리거(언제 기록하는가)만 정의한다.** 기록 형식·저널 규약·페이지 구조는 `obsidian-write` 스킬, vault 위치/namespace 매핑은 `documentation` 스킬 소유.

| 조건 | 행동 |
|------|------|
| 세션 내 git commit 3회+ 또는 PR 생성 | `/debrief` 제안 |
| 코드 작업 반영 완료 | 당일 저널에 결과 기록 제안 (`- [ ]` → `- [x]` 전환 + 요약). namespace 페이지가 적절하면 함께 제안 |
| 슬랙/이메일 내용 붙여넣기 | 관련 issue 페이지 갱신 제안 (없으면 생성 제안) |
| open issue 페이지 Read | `last-verified::` 갱신 제안 |
| 외부 의존성 있는 작업 시작 | issue 페이지 생성 제안 |
| **사용자 세션 종료 신호** ("여기서 종료", "끝", "정리해줘", "오늘 여기까지" 등) | 당일 저널에 `- [x] {작업 요약}` **기록한다**. `/debrief` 제안 |
| **스킬/룰/훅 등 하네스 수정** | 당일 저널에 `- [x] {변경 요약}` **기록한다** |
| 다단계 + 외부 의존 작업 (계획 체크박스 3개+, 여러 세션 진행) | Living Plan으로 관리 — 형식은 obsidian-write |
